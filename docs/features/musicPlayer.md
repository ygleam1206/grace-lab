# 主页网易云音乐播放器

## 目标

在当前个人知识库网站的左上角增加一个精简的网易云音乐播放器，支持在网站内播放音乐，并尽可能保持现有主页布局不变。

## 开发前检查

1. 检查当前主页组件结构、导航栏和左上角现有元素。
2. 确认项目使用的 Next.js、React、TypeScript 版本。
3. 调研网易云音乐当前支持的官方嵌入方式，以及歌曲播放、版权和外链限制。
4. 先说明实现方案及限制，再开始修改。

## UI 要求

- 播放器采用小型、简洁的设计，与当前网站蓝紫色背景、玻璃质感风格一致。
- 优先放在左上角现有空白区域，不得挤压或移动现有标题、导航栏、按钮和其他组件。
- 播放器应支持折叠或展开，避免占用过多空间。
- 显示歌曲封面、歌曲名称和歌手名称（在可获取时）。
- 提供播放、暂停、音量控制；只有在播放源支持时才提供上一首、下一首。
- 窄屏设备上不得遮挡主要内容。

## 播放功能

- 优先使用网易云音乐官方支持的嵌入播放器或播放方式。
- 不得假定任意歌曲的 URL 都可以直接播放。
- 如果官方方式不支持自定义播放控制，应明确说明限制，不要伪造可用的播放功能。
- 如果需要用户提供歌单或歌曲链接，请提供清晰的配置入口。
- 浏览器禁止自动播放时，应允许用户点击按钮后开始播放。
- 播放失败时显示友好的错误提示，并提供打开网易云音乐原页面的入口。
- 不要绕过版权限制、登录验证或访问控制。
- 不要将 Cookie、账号凭据或其他敏感信息写入前端代码。

## 技术要求

- 复用当前项目技术栈和现有依赖。
- 尽量封装成独立的 MusicPlayer 组件。
- 播放器状态和音频资源管理应与主页布局解耦。
- 正确处理组件卸载、音频资源清理和播放失败。
- 不要为了这个功能引入不必要的大型依赖。

## 修改范围

只修改音乐播放器及其必要的样式、配置和主页挂载位置。

禁止重构整个主页，禁止改变已有标题、导航栏、文字、按钮、统计卡片的位置和尺寸，禁止修改笔记、文件、学习计时器和统计图表等无关功能。

## 验收标准

1. 播放器出现在指定位置。
2. 原主页布局不发生变化。
3. 用户点击播放后，能够播放配置的歌曲（前提是播放源允许）。
4. 播放、暂停、音量控制与实际播放状态一致。
5. 播放失败时能够给出提示，而不是显示虚假的播放状态。
6. 刷新页面后播放器仍能正常显示。
7. 窄屏下不会遮挡主要内容。
8. 汇报修改文件、播放方式、已知限制和测试结果。
